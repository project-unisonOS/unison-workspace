# Resolution, development topology, and hardware pathway evidence

Status: software and static foundation complete

Date: 2026-08-15

## Resolution and determinization

Versioned contracts represent bounded resolution attempts, partial outcomes,
receipts, and non-executable determinization candidates. Person-scoped context
persistence rejects cross-person reads. Promotion is sequential, reviewed,
signed, canaried, and reversible. An unfamiliar household repair fixture proves
deterministic-first routing, bounded local inference, cancellation, uncertainty,
and resumable partial progress.

## Native expression

Conversation, Braille, and visual composers consume one semantic outcome but
produce independent modality structures. Blind and visually impaired use does
not depend on a visual screen, DOM focus, ARIA representation, or screen reader.
The evidence is simulation only and does not claim representative-device or
participatory validation.

## Development topology

Windows and Codex are the control plane. The Ubuntu dev NUC is the canonical
Linux build and integration host over local SSH or Tailscale SSH. A PowerShell
wrapper exposes bounded remote bootstrap, validation, unit, boundary, and status
commands. The wrapper does not forward secrets or make Windows a deployment
host. Clean-clone onboarding validation checks the agent guide, repository map,
task schema, topology, and exact entrypoints.

## Hardware pathway

The hardware repository now records compute, memory, RAID storage, networking,
security, radio and sensor, power and thermal, and enclosure backplane
boundaries. A budgetary concept BOM, power and thermal envelope, branded
enclosure requirements, and open editable-source conventions are validated.
These records do not select 2027 or 2028 parts and do not authorize fabrication.

The deferred dual-GPU workstation plan names inventory, inference, rebuild,
power and thermal, and resilience groups. Inventory collection is executable.
Load qualification fails closed until the workstation, fixtures, and measurement
adapters are named.
