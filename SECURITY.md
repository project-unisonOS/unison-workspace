# Security

This repo follows the org-wide security policy in `.github/SECURITY.md`. Report vulnerabilities privately to **darryl.adams@accessinsights.net**; do not open public issues.

Changes affecting authentication, authorization, consent, encryption,
compartment boundaries, external disclosure, network exposure, update trust,
incident response, or physical actuation require threat-model impact notes,
abuse-case tests, rollback instructions, and review by
`@project-unisonOS/security-leads`. Do not place vulnerability details in agent
task packets, public issues, CI logs, or PR descriptions.
